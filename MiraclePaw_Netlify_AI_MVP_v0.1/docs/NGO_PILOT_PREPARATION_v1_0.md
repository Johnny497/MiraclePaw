# MiraclePaw 星爪 — NGO Pilot Preparation Pack v1.0

**狀態：內部候審草案 / NO-GO — 不可啟動真實服務試點**  
**用途：**供獲邀成年 NGO／學校社工、危機支援、私隱、安全及研究方法專業持份者，以虛構劇本進行初步討論。  
**範圍：**不包括未成年人試用、真實個案、心理治療、診斷、療效證明或任何對外招募。

> 呢份文件係討論底稿，**唔係**合作協議、資料收集同意書、PICS 完稿、倫理批准或安全合格證書。任何文件簽署、責任人指定與決策紀錄，必須在合作機構核准嘅正式系統另行完成。請勿將個人資料或真實服務使用者紀錄寫入 GitHub Repository。

- 五個**虛構、固定**展示劇本；不是 AI 即時回覆。
- 可選嘅真 AI 文字聊天 Demo。現時 API 配額、穩定性及安全性**不保證**可作真實支援。
- 顯示香港撒瑪利亞會 **2389 2222**、生命熱線 **2382 0000**；即時危險提示 **999**。保持陪伴；不暗中通知第三方。
- 沒有真人配對、即時定位、已投入服務的家長或 NGO 後台。

### 尚未完成（不可當成成就）

## 2. 合作建議的三個階段

| 階段 | 可做／擬議工作 | 不可越界事項 |
|---|---|---|
| A — 成年專業人員評審 | 以固定虛構劇本召開專業交流；整理風險、同意與功能問題（如需記名須先批准處理方案） | 不招募服務使用者、學生／未成年人；不收集真實情緒或醫療資料 |
| B — 共同設計與獨立審查 | 共同草擬責任分工、風險矩陣、危機應對、資料流、同意及撤回方案，提交適用審查 | 不把草稿或演示勾選當已獲批准 |
| C — 可能的獲批研究 | **只有**完成必要書面批准、專業安全驗證及合作協議後，另行評估受試者招募、研究設計及支援能力 | v1.0 沒有任何正式開啟 Phase C 的功能 |

## 3. 第一場 45 分鐘專業評審會議

| 時間 | 議題 | 需釐清之重點 |
|---|---|---|
| 00–05 | 用途／限制 | 成年持份者、全部虛構、不取代社工 |
| 05–15 | 小貓互動與自主權 | 拒絕、沉默、取消出門、無懲罰 |
| 15–25 | 安全／危機與停用 | 香港熱線、誤判、人工支援責任、不可暗中通報 |
| 25–35 | 真正資料流向 | Mood page-memory；AI chat 透過 Netlify 發送至 OpenAI；供應商日誌待查 |
| 35–45 | 合作與下一步 | 確定責任人、需準備證據及 NO-GO 原因；不現場招募 |

會議結果應記錄於 NGO 正式核准的工作系統，而不是 Demo 網站或公開 Repository。

## 4. 上線前六個不可代替的審查項目

1. **適用範圍／不適用情況**：清楚列明虛擬陪伴、非醫療與拒絕任務保障；由合作方檢視文案是否施壓。
2. **危機安全**：由具適當資格的專業人士提出測試、人工承接、停用與誤判處理；目前關鍵字／moderation 不是臨床風險評估。
3. **私隱與資料流**：盤點傳往第三方的對話、API 供應商、平台日誌、處理地域、保留及刪除；完成必要告知、同意、存取權限與處理安排。
4. **倫理／未成年人保障**：成年人自我勾選不等於年齡核實；如涉及服務使用者，必須另行處理適用審批及保障要求。
5. **可用性與研究方法**：由專業人士先測虛構劇本是否清楚、危機資源是否易理解；未有樣本或研究，不可聲稱改善心理健康。
6. **機構承接／角色責任**：需有書面角色、支援時段、負面事件應對、投訴、退出與試點停止權責。

**全部討論過 ≠ 全部達成。** 任何一項缺乏適用書面批准／實證，都維持 NO-GO。

## 5. 現有資料流及未來權限

| 項目 | v0.9 代碼可見狀況 | 試點前必須覆核 |
|---|---|---|
| 固定展示劇本 | 靜態文字，無需 OpenAI API | 初次載入網頁／平台使用紀錄與安全 |
| 心情選擇 | 僅現有分頁記憶體、最多 10 項、可手動清除 | 未來如新增儲存需另行評估告知、同意及刪除 |
| 真 AI 聊天 | `/api/chat` 將當次訊息及部分歷史交 Netlify Function，再至 OpenAI Moderations／Responses；Responses 設 `store:false` | API／平台日誌、保留、地域、處理協議、是否可提供服務、危機安全 |
| 出門微行動 | 只係模擬；無 GPS、無真實打卡資料庫 | 禁止即時定位；未來有紀錄須自願同意 |
| 家長／NGO 報告 | 未實作 | 若將來獲批：家長只看進度，社工／NGO 只看經同意的情緒分數／外出紀錄；**任何第三方不可看對話原文** |

**重點：**不能聲稱真 AI 對話「從不出裝置」。現有程式沒有聊天資料庫，不等於所有外部供應商均完全沒有日誌。

## 6. 初步風險（非正式評級）

| ID | 風險 | 初步應對／停止條件 |
|---|---|---|
| R01 | 危機漏判或錯誤建議 | 專業審查及虛構風險測試；發現不安全即停止真人試用 |
| R02 | 未成年人誤入成年原型 | 僅受邀成年專業評審；無授權即撤回入口 |
| R03 | 敏感對話外洩或第三方讀原文 | 核實供應商及權限；未核清即不處理真人資料 |
| R04 | 用戶因寵物而感到被強制出門 | 不扣分／撤回陪伴；移除任何施壓文案 |
| R05 | AI API／moderation 不可用 | Fail closed；只用安全固定劇本展示 |
| R06 | 對外聲稱已有合作或療效 | 必須有可核實證據，否則更正／撤下聲稱 |
| R07 | NGO 人手／危機責任不清 | 無正式承接、培訓或停用責任即 NO-GO |
| R08 | 把虛構寵物誤作真人配對或定位 | 明確標註虛構，禁止真人 GPS／強制配對 |

需由正式委任專業人士獨立制定風險矩陣、責任人、完成時限及殘餘風險是否可接受，不能由本 Demo 網頁代判。

## 7. 建議評估問題（不收集資料）

第一輪成年專業審閱，可用 **虛構** 情境觀察：使用者能否拒絕任務？是否清楚固定劇本不是真 AI？是否辨識危機熱線？專業人士能否找出不安全回覆／不清楚資料流？有否無意增加社工工作負荷？

這些屬建議評審維度，**不是已有數值或成效**。日後若要評估心理或健康結果，需另有適當的倫理與研究方法。
