# MiraclePaw 星爪 — NGO Activity Proposal Kit v1.2

**範圍：**成年 NGO／社工持份者虛構情境討論；不是已獲批活動、實地考察報告、青年研究或照片授權文件。  
**目前決策：NO-GO — 無正式 NGO／研究／服務使用者試點許可。**  
**資料來源定位：**此版參考團隊提供的青年活動簡報圖片及 AI 製作 PPT 工作流程之**結構與議題**，不是驗證圖片內場地／機構與星爪有任何關係。圖片中提及的「友愛共融大灣區計劃2026」、深圳新興商場、前海深港青年夢工場與深圳大學附屬華南醫院，只是參考內容，不得當作星爪已受邀、已考察、合作或獲背書的證據。

## 1. 方向與限制

本版只提供三個供專業討論的**主題假設**，並不宣稱有真人訪談、青年普遍需求數據或臨床結果：
1. **青年社區參與** — 探討自願、低壓、可完全拒絕的社區互動；室內活動可作選項，不以外出換取虛擬寵物陪伴。
2. **青年就業／技能** — 探討資料整合、求職或 AI 負責任製作 PPT 等數碼技能概念工作坊；唔承諾改善就業。
3. **青年健康／情緒** — 僅邀請合資格成年專業人員用虛構危機／低落劇本評審支援資訊；非醫療、非診斷、非真人危機介入。

以上三類可作 NGO 初次意見交換的例題。星爪尚未有相關 NGO 合作、倫理批准、兒童保障驗證、真人活動、現場考察或成效。

## 2. 四條建議問題

- 我們正面對哪個**未驗證**的問題／機會？
- 可能的需要是甚麼，哪些必須由 NGO／社工／專業人士核實？
- 我們能提出甚麼可退出、不強制的活動概念？
- 要安全推行，需甚麼資源、保障及正式批准？

注意：提出問題**不是**聲稱已有調查結果。

## 3. 八頁簡報框架（每主題皆有固定草稿）

| 頁 | 主題 | 審閱重點 |
|---|---|---|
| 01 | 封面／概念 | 清楚寫「建議」，不要用圖片冒充星爪成果 |
| 02 | 參考場景／考察方向 | 非實地考察；場地資料／相片需另行查證 |
| 03 | 我們想了解甚麼？ | 問題假設，不是已得的結論 |
| 04 | 最值得驗證的發現 | 無訪談／調查結果時，必須稱「假設」 |
| 05 | 青年面對的問題 | 請專業人士核對是否適用；避免標籤化 |
| 06 | 青年可能的需要 | 尊重不同群體及拒絕參與的權利 |
| 07 | 我們的活動建議 | 清楚寫對象、可退出、風險、所需合作 |
| 08 | 資源、風險與下一步 | NGO／倫理／保障／私隱未批准，維持 NO-GO |

網站 `/activity.html` 會按三個主題切換固定文字，提供**複製大綱**及**列印／另存 PDF**。不會讀用戶附件、上傳照片、生成真實 PowerPoint 檔、收集 NGO 聯絡人或使用者資料。

## 4. AI 整理工作紙及 PPT 的人手核對流程

1. **整理資料：**只使用虛構、自創或獲適用許可的工作紙／相片；不要上傳真實未成年／服務使用者的個案、醫療／情緒資料。
2. **生成大綱：**利用 `/activity.html` 八頁草稿作討論起點；AI 幫整理不等於資料已核實。
3. **檢查圖片：**確定著作權、拍攝者及人物肖像等使用權限；不能把其他團體活動照片當成星爪真實活動。
4. **製作 PPT：**按經批准的內容於團隊使用工具自行排版、加照片及出處。v1.2 **沒有** .pptx 檔輸出或 AI 圖片自動配對。
5. **發送前 QA：**逐頁核對日期、機構、地點、證據、危機措辭、未獲審批事項；由項目負責人作最後核實。

## 5. 安全及資料治理

- **從不懲罰：**用戶唔出門、唔做任務、唔分享心情，都唔會扣分、令寵物飢餓或失去陪伴。
- **禁止強制配對／GPS 即時定位：**虛構寵物不等於真人使用者，外出永遠自願。
- **第三方對話原文：**任何未來家長／NGO 後台均不得閱覽聊天原文；目前該類後台尚未實作。
- **真 AI 服務界線：**v1.2 活動頁是純靜態；既有主網站可選真 AI 聊天會將文字及部分上下文經 Netlify Functions 傳往 OpenAI API，供應商留存、同意及私隱仍待正式審查。
- **危機界線：**保持陪伴，顯示香港撒瑪利亞會 2389 2222、生命熱線 2382 0000，遇即時危險提示 999；唔暗中通知第三方。此流程未經獨立臨床危機安全驗證。
- **未成年保護：**此網站僅成年人持份者 Demo，成年人勾選不是年齡核實。不能藉 PPT 工作坊話題就直接招募青年／學生。

## 6. NGO 交流建議

首次交流可用 v1.1 `/partners.html` 合作邀請資料；如 NGO 有興趣才由成年專業人員檢視假設及虛構劇本。是否有任何下一步，須返回 v1.0 `/pilot.html` 既有六大審查關口，確認獨立責任人、適用批准、資料最小化、退出及事故流程。**任何會議、圖片或活動靈感不會自動改變 NO-GO 決定。**

此文件不是正式活動企劃書或合作協議，沒有可供招募的活動日期、場地、費用或已確認人手。若日後需要實際 PPT，應使用新批准且具來源、權利和書面證據的資料再製作。
