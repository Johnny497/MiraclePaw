# MiraclePaw 星爪 — NGO Partnership Toolkit v1.1

**文檔性質：非約束性、供成年專業持份者審閱的合作邀請草稿。**  
**目前決策：NO-GO，不能啟動真實服務使用者／未成年人試點。**  
**產品階段：**已具備成年內部演示版及 v1.0 NGO Pilot Preparation；尚未有經證實的 NGO 合作協議、倫理批准、臨床結果、獨立危機安全驗證或兒童保障授權。  
**使用指引：**此文件不得直接寄出予任何 NGO 而不先核對名稱、對象、語氣、數據真實性、法律／保障界線及團隊授權；不要在此 Repository 留存合作機構個人資料、電郵地址、真人個案或會議紀錄。

## A. 我們希望 NGO 先幫忙什麼？

邀請合適的 NGO／社工進行 **約 30 分鐘自願、非約束性的成年專業交流**，以虛構劇本評論：
1. 本產品可／不可適用於哪些服務情境；
2. 是否足夠尊重「不說話、不外出、拒絕任務」；
3. 粵語情緒文案、危機提示及轉介責任可能有何風險；
4. 真 AI 對話資料流、權限及使用者告知是否清楚；
5. 是否值得安排第二輪獨立專業評估。

**這不是要求 NGO 提供服務使用者或學生作試點，不是同意研究，更不是請機構作臨床認證。**

### 已有的產品原型（可展示，不等於已證成成效）
- 廣東話虛擬寵物、可選的互動與心情選擇；不出門、不做任務也不會失去陪伴，無飢餓懲罰或分數壓力。
- 五個虛構固定劇本，包括拒絕微行動、低落陪伴、危機資源、虛構寵物互動；無真人 GPS 或強制配對。
- 可選真 AI Demo；文字和部分歷史會經 Netlify Function 及 OpenAI API，平台／供應商資料保留須獨立審查。不可聲稱所有聊天永不離開裝置。
- 已有 v0.9 NGO／HKSEC Pitch 及 v1.0 六關口／八風險準備包，但未有服務使用者真人驗證或臨床效果。
- 基本陪伴方向為永久免費，不加廣告或付費牆。

我哋現時有可操作嘅成年持份者展示版及五個虛構固定劇本，但未有真人試點、已證實嘅心理健康成效、適用未成年人嘅安全驗證，亦未獲任何正式 NGO 合作或倫理批准。星爪唔係心理治療、診斷或危機介入服務。

## D. 適合聯絡的 NGO：討論題目（不評分）

只以 **服務適配、專業能力與雙方意願** 作人手初步篩選，別在本頁記錄機構名稱或私人聯絡資料。考慮：
- 是否願意聽取非醫療數碼陪伴概念，同時清楚了解目前仍未驗證；
- 是否有獲授權成年社工或相關專業人士願意對虛構場景提出意見；
- 是否清楚何時應轉介危機、私隱及兒童保障專業人士；
- 是否有可承擔的時間與資源，及明確停止參與的自由；
- 若不感興趣，不施加壓力、無反覆追問或默示同意。

透過 NGO **官方公開聯絡渠道** 自行核對收件人／機構，團隊負責人先核實內容，再在適當電郵系統人手發送。本網頁不查找收件人、發信或追蹤回覆。

## E. 初次 30 分鐘會議議程

| 時間 | 主題 | 問法 |
|---|---|---|
| 00–05 | 介紹定位及限制 | 「星爪原型唔係治療；你哋認為有咩場景絕對唔適合？」 |
| 05–12 | 虛構劇本示範 | 「拒絕任務時會唔會仍然感到壓力？」 |
| 12–22 | 危機、安全、私隱、工作量 | 「邊啲風險應先交獨立專業人士評估？」 |
| 22–30 | 是否合適有下一輪交流 | 「如果有第二次交流，需要先補邊啲文件？由邊個有權作決定？」 |

如要深入審查安全及資料流，可**另行建議**採用 v1.0 的 45 分鐘工作坊。初次交流不能代替正式倫理、危機安全或法規審核。

## G. 非約束性合作討論綱要（不是可簽 MoU）

1. **目的／範圍：**限用虛構材料進行成年專業概念討論；任何後續研究須另議。
2. **地位：**邀請、會議、意向草稿不構成正式合作、使用者招募許可或倫理批准。
3. **私隱／資料：**初次交流不分享真人個案、姓名、情緒紀錄或聊天原文；任何未來資料處理另議適用書面文件及同意。
4. **安全與保障：**危機應對、事故通知、停止權、未成年保障須由具資格人士與機構審查，不能以 Demo 代替。
5. **資源與財務：**不預設 NGO 有免費人手、資助、場地或服務時間承諾。
6. **品牌／知識產權：**無對方書面許可不得用其名稱、商標、報告或意見作代言／背書。
7. **終止／退出：**任何一方可選擇停止討論；若將來正式合作，需另定清楚終止條款。
8. **正式文件：**只有雙方授權代表及適當顧問另行審閱、簽署後，才可能產生有約束力的責任。

⚠️ 本文件不構成法律意見或已審核的 MoU。不能將以上條款自行當作適用法律要求的完整清單。

## H. 發信及跟進操作規則

1. 在 `/partners.html` 成年確認後切換中文／英文及草稿種類。
2. 獨立核對 NGO 官方資料，確認收件人及適配性。不要將名字／電郵填在網頁或 Repo。
3. 複製草稿到**團隊正式電郵系統**，填好方括號資料，確認事實／附件／內部授權後再發出。
4. 如對方無回覆，只按機構合適禮儀作一次禮貌跟進；無意願就停止。
5. 如獲邀交流，只用成年專業人士及虛構固定劇本；不要現場收集健康、情緒或學生資料。
6. 如有會後摘要，要交對方核實；正式會議紀錄／聯絡資料只能保留喺獲批准嘅內部系統，且遵守相應私隱流程。
7. 之後任何真人服務或研究仍返回 `/pilot.html` 六大門檻及 NO-GO 審查，**不會因為交流順利而自動解鎖**。

## I. 本版明確不會做的事

- 不自行聯絡 NGO、寄出電郵、讀 Gmail、記錄對方姓名或回覆。

- 不開放學生／未成年人、真人個案、醫療記錄或心理評分資料收集。
- 不新增真人配對、GPS、家長／社工原文聊天後台、強制外出或任何行為懲罰。
- 不聲稱完成法律合規、獨立安全驗證、臨床效果、合作協議或已開啟 Pilot。
